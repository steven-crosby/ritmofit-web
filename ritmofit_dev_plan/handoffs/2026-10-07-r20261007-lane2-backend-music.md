# Apple Music library pagination cycles reject before repeated requests

## Done

- Work commit `12d5ce2` adds a visited-path guard to library songs, library playlists,
  and library playlist tracks. An exact repeated request path raises a generic `ProviderError`
  before another upstream request, rather than looping or returning earlier partial results.
- Added nine regression/compatibility cases across those three readers. Catalog pagination,
  existing caps, empty-page handling, 404 behavior, and reconnect handling remain unchanged.
- Reverified Apple's pagination documentation on 2026-10-07:
  <https://developer.apple.com/documentation/applemusicapi/fetching-resources-by-page> describes
  `next` as a subpath containing the next page's offset.
